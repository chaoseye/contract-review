# Дополнительные шрифты

Файлы из этой папки копируются в образ (`/usr/local/share/fonts/contract-review/`), их видит LibreOffice при сборке PDF.

Сюда кладутся только шрифты с лицензией, которая разрешает распространение, например SIL OFL. Рядом с шрифтом лежит файл его лицензии.

Сейчас папка пуста:
- контакты в колонтитуле протокола набираются шрифтом текста, отдельный шрифт для них не нужен;
- Times New Roman сюда не кладётся: у Microsoft свои условия распространения. В PDF его заменяет метрически совпадающий Liberation Serif.
